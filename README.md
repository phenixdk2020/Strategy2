# Strategy2 — PROJECT 1864 Unreal P0A

Unreal-kanal for PROJECT 1864. Unity-prototypen og designmanualen bor stadig i:

https://github.com/phenixdk2020/Strategy

Dette repo er den første Unreal Engine 5.5+ P0A battle-slice. Den følger designmanual v00.02.08 og Unity P0A v00.00.08.

## Åbn i Unreal

1. Installér Unreal Engine 5.5 (eller ret EngineAssociation i Strategy2.uproject).
2. Clone dette repo og branch p0a-unreal-v00.00.08.
3. Dobbeltklik Strategy2.uproject, compile C++-modulet Strategy2.
4. Play In Editor. GameMode P1864GameMode bygger slagmarken runtime.

## Styring

Venstreklik vælg dansk regiment. Shift+klik multi-select. Højreklik flyt/angrib.
F line, C column, H hold. WASD kamera, Q/E rotér, hjul zoom.
Space pause, 1/2/3 speed, R restart.

Design-source of truth: phenixdk2020/Strategy/docs/PROJECT-1864-Designmanual.md
